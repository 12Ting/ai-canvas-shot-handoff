## 本机练习

按[启动说明](../README.md)准备好运行环境，在项目根目录运行：

```powershell
.\start.cmd --demo
```

这会创建一个独立的三镜合成项目，可以自由改选、补写理由，再导出自己的交接包。练习数据保存在 `.local/paper-boat-selection/`，再次启动会保留上次的操作。

也可以直接解压[练习项目的选片包](paper-boat-selected.zip)或[单条补镜包](paper-boat-issue.zip)，双击其中的 `index.html` 查看离线交接页。
