# 纸船选片样例

一艘纸船从左向右经过灯下。第二镜拍了两个方向，剪辑该拿哪条？

1. 解压[整片选片交接包](paper-boat-selected.zip)，双击 `index.html`。在第二镜「经过灯下」能看到采用的是 `SH02-向右.mp4`，理由是「纸船和前后镜都向右，剪在一起方向连贯。」三个镜头的采用版都在 `定稿` 目录。
2. 同一镜下还有一条意见，指向 `SH02-向左.mp4`，要求改方向、保留提示音。接手人要重做这一版时，再打开[单条补镜包](paper-boat-issue.zip)，里面有当时的原片、前后镜、参考图、声音和提示词。

两个包都能离线查看。想看它们在工作台里怎样产生，可以看[选片演示](paper-boat-demo.mp4)。样例画面和声音由随项目提供的 Python 程序绘制、合成。

## 在自己的本机复现

完成[运行环境准备](../README.md)后，在项目根目录运行一次即可打开样例。

```powershell
.\start.cmd --demo
```

首次启动会创建 `.local/paper-boat-selection`，之后会打开同一份样例。进入「纸船选片样例」的第二镜，切换两个方向，分别播放。可以试着改选、补写一句理由，再导出自己的选片包。

样例的工作目录在 `workspace/`，独立的应用数据在 `database/`。初始两份 ZIP 的异地解压副本在 `receiver/`；脚本会检查页面链接和素材哈希，把结果写入 `verification.json`。旧版「纸船接戏样例」仍可用 `scripts/handoff_demo.py --out .local/paper-boat --open` 打开。
